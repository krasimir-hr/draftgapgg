# Playoff bracket administration

Open a playoff overview and choose **Admin sign in**. Use an existing Django account marked **Staff status** (superusers also qualify). The app uses the existing JWT login API. Public visitors can read matches but cannot save bracket changes.

Choose **Edit bracket**, then drag a match into an upper, lower, or final zone. Drop it above another match to reorder the series. The selected match can also be moved with the destination selector and **Move** button, which supports keyboards and touch devices. Cards use organization short names. Drag the **W →** handle onto another match to connect the winner; clicking the handle and then its destination works with touch or keyboard too. Winner connections have arrows; loser destinations are shown as text such as HLE to lower bracket. **Winner advances to** and **Loser advances to** selectors provide another way to set or clear each link. Winners advance to a later round; losers advance to a lower match in a later round or drop from upper to lower within the same round; moving a match clears connections that would point backwards. Placement matches remain separate.

Use **+ Add round / stage** and **+ Add final** to create columns. Each column has an editable name, for example Play-in, Quarterfinals, Semifinals or Grand final. The × beside each column name removes that stage, moves its matches to the unplaced list, and clears connections to those matches. All stages can be removed; add a new one before restoring matches. Cancel discards these edits and Save layout persists them. Names and empty columns are saved separately from match placement, scoped to the current playoff view. Removing every match therefore leaves the saved structure available, and a previously cleared bracket can be rebuilt with these controls.

Loser labels are inferred from recorded outcomes and later fixtures, including hidden matches. Completed elimination-series losses show **TEAM eliminated**. Select a match and use **Loser label** to choose Automatic, Eliminated, To lower bracket, or Hidden if imported information is incomplete. Overrides save with the layout.

Every editor card shows its local date/time and final score when recorded. The × button removes a match from the layout into **Unplaced matches**; Restore or dragging it back returns it. Saving removals hides matches only from the bracket, preserving the match feed, results and statistics. Incoming connections to removed matches are cleared. An entirely empty bracket remains editable.

**Save layout** stores positions, bracket paths, final flags, and separate winner/loser connections together. Scores, teams, dates, and original imported round names are unchanged. **Cancel** discards the draft. Changes become public only after saving, and the page reloads its data automatically. An expired session prompts for sign-in while retaining the draft.

`POST /api/matches/bracket-layout/` accepts an event ID and match placements. The server enforces staff access, same-event/stage connections, distinct positions, and forward winner paths. It clears occupied positions before applying swaps inside one transaction. Existing per-match bracket and rename-column endpoints are also staff-only. Apply the `0020_match_bracket_hidden`, `0021_loser_bracket_connection` `0022_persistent_bracket_rounds` and `0023_loser_outcome_override` migrations before deploying this editor.

Select a match and use **Team entry sources** to show where either team joined the bracket. Examples: `Regular season · 1st`, `Seed 2 · Bye to Round 2`, or `Winner of Round 1`. Labels appear below each team name on the public bracket; hover to read a longer label. Blank labels stay hidden. Labels are manual, persist with Save layout, and are not overwritten by older layout clients that omit the fields. Apply migration `0024_match_entry_sources` before deployment.

The **Qualified teams** column includes all known teams from the playoff fixtures, including hidden series. It remains separate from matches. In the editor, drag a team's arrow onto its opening match (including any later round), click its arrow and then a match, or use the team's **enters at** selector. Seed / regular-season-finish labels are editable on each team card. Save layout persists these entries per playoff view; removing a destination clears its entry arrow but retains the team. Apply migration `0025_qualified_bracket_entries` before deployment.
