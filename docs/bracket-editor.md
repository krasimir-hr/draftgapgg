# Playoff bracket administration

Open a playoff overview and choose **Admin sign in**. Use an existing Django account marked **Staff status** (superusers also qualify). The app uses the existing JWT login API. Public visitors can read matches but cannot save bracket changes.

Choose **Edit bracket**, then drag a match into an upper, lower, or final zone. Drop it above another match to reorder the series. The selected match can also be moved with the destination selector and **Move** button, which supports keyboards and touch devices. Cards use organization short names. Drag the **W →** or **L →** handle onto another match to connect the winner or loser; clicking a handle and then its destination works with touch or keyboard too. Solid arrows represent winners, dashed arrows represent losers. **Winner advances to** and **Loser advances to** selectors provide another way to set or clear each link. Winners advance to a later round; losers advance to a lower match in a later round or drop from upper to lower within the same round; moving a match clears connections that would point backwards. Placement matches remain separate.

Every editor card shows its local date/time and final score when recorded. The × button removes a match from the layout into **Unplaced matches**; Restore or dragging it back returns it. Saving removals hides matches only from the bracket, preserving the match feed, results and statistics. Incoming connections to removed matches are cleared. An entirely empty bracket remains editable.

**Save layout** stores positions, bracket paths, final flags, and separate winner/loser connections together. Scores, teams, dates, and original imported round names are unchanged. **Cancel** discards the draft. Changes become public only after saving, and the page reloads its data automatically. An expired session prompts for sign-in while retaining the draft.

`POST /api/matches/bracket-layout/` accepts an event ID and match placements. The server enforces staff access, same-event/stage connections, distinct positions, and forward winner paths. It clears occupied positions before applying swaps inside one transaction. Existing per-match bracket and rename-column endpoints are also staff-only. Apply the `0020_match_bracket_hidden` and `0021_loser_bracket_connection` migrations before deploying this editor.
